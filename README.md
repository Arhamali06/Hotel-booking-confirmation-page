## Overview

### The challenge

Users should be able to:

- View an appropriate layout across desktop and smaller screens
- View the booking receipt, host welcome card, and guest information cards
- See navigation and overlapping-card hover states

The optional mobile navigation menu and Wi-Fi password copy interaction have not been implemented because this project currently uses HTML and CSS only.

## My process

### Built with

- Semantic HTML5 markup
- CSS custom properties
- Flexbox
- CSS Grid
- Responsive CSS with a `900px` breakpoint
- Local SVG image assets
- Google Fonts: Inter and Playfair Display

### What I learned

This project was a useful exercise in combining CSS Grid for the main page structure with Flexbox for smaller interface groups. The overlapping receipt and welcome cards use absolute positioning, transforms, and transitions to create a layered layout with a hover interaction.

I also practiced using CSS custom properties to keep the warm color palette consistent and using responsive rules to move the sidebar above the main content on smaller screens.

### Continued development

In future iterations, I would like to add JavaScript for the optional Wi-Fi password copy button, a toggleable navigation menu on small screens, and functional print and calendar buttons.
